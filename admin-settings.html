Backups

A backup of all five databases is created automatically on the 1st of every quarter (Jan · Apr · Jul · Oct) at 3:00 AM IST, into a Drive folder named GPN-BACKUPS. Each run produces 5 file copies.

To run a manual backup right now, open the Apps Script project → Editor → select the function createBackups_ → Run.
